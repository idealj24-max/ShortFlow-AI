# 🎬 ShortFlow AI — Viral Short-Form Script & Storyboard Studio PWA

**ShortFlow AI** est une application web progressive (PWA) mobile-first conçue pour les créateurs de contenu TikTok, YouTube Shorts et Instagram Reels. Elle génère en quelques secondes des hooks psychologiques anti-scroll, des scripts chronométrés haute rétention et un découpage visuel complet.

🌐 **Tester l'application en live :** [https://idealj24-max.github.io/ShortFlow-AI/](https://idealj24-max.github.io/ShortFlow-AI/)

---

## 🚀 Fonctionnalités
* **🪝 Générateur de Hooks (0-3s) :** 3 accroches psychologiques optimisées pour maximiser le taux de rétention initial.
* **🎙️ Script Chronométré :** Structure narrative complète adaptée à la durée choisie (30s, 45s, 60s).
* **🎥 Storyboard & B-Rolls :** Indications précises de plans caméra et d'éléments visuels scène par scène.
* **💾 Bibliothèque Locale & Export Markdown :** Sauvegarde hors-ligne et exportation rapide en `.md`.
